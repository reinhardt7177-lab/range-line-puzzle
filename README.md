# 경계의 성 — 수학 탐험대

> 초등학교 5학년 2학기 수학 1단원 「수의 범위와 어림하기」를 11개의 관문을 통과하는 퀘스트로 바꾼 브루탈리즘 학습 웹앱입니다.

**경계의 성**은 아이스크림 교과서·지도서의 학습 요소를 바탕으로, 이론을 읽고 여러 문항을 해결한 뒤 관문 보스 문제를 통과하는 학습 흐름을 제공합니다. 교과서의 장면을 그대로 복제하기보다 **범위 판단, 어림하기, 경계값, 수직선 표현, 실생활 조건 해석**을 반복해서 연습하도록 설계했습니다.

## 핵심 학습 흐름

학습자는 지도에서 현재 관문을 선택하고, 차시 브리핑에서 핵심 개념을 확인한 뒤 문항을 한 문제씩 풉니다. 관문의 정규 문항을 모두 통과하면 개념을 종합하는 보스 문제로 이동하고, 보스까지 해결하면 다음 관문과 길이 열립니다.

```text
퀘스트 지도
  ↓
차시 브리핑·핵심 개념
  ↓
정규 문항 풀이
  ↓
정답·오답·힌트 피드백
  ↓
관문 보스 문제
  ↓
특별 칭호 획득·다음 길 해금
  ↓
11관문 완주 시 성 복구 엔딩
```

## 게임 규칙

### 관문과 문항

1단원은 총 11개 관문으로 구성됩니다. 각 관문은 지도서의 차시 목표에 대응하며, 지도 화면에는 현재 관문·완료 관문·봉인 관문이 구분되어 표시됩니다. 정규 문제는 관문당 18문항을 중심으로 구성되고, 시각·조작형 보강 문항을 포함해 지도 표기 기준 총 **209문항**을 제공합니다. 관문별 보스 문제 11개는 정규 문제은행과 별도의 최종 도전으로 동작합니다.

| 문항 요소 | 학습 목적 | 풀이 방식 |
|---|---|---|
| 기본 개념 | 이상·이하·초과·미만, 올림·버림·반올림의 기본 규칙 확인 | 선택형·직접 입력 |
| 적용 문제 | 실생활 조건에서 범위와 어림 방법 선택 | 선택형·복합 조건 |
| 오개념 교정 | 끝점 포함 여부, 어림 기준, 단위 착각 교정 | 선택형·해설형 |
| 수직선 문제 | 채워진 점·빈 점·화살표 방향·경계값 읽기 | SVG 판독·직접 조작 |
| 요금표 문제 | 무게·크기·조건별 요금을 표에서 읽고 해석 | 표 판독·선택형 |
| 묶음 그림 문제 | 상자·스탬프 묶음을 보고 올림·버림 결과 판단 | 시각 자료·선택형 |
| 직접 입력 문제 | 계산 결과나 기준값을 숫자로 표현 | 숫자 입력 |
| 보스 문제 | 해당 차시 핵심 개념을 종합적으로 적용 | 별도 보스 화면 |

### 정답과 오답

문항을 선택하거나 답을 입력한 뒤 제출하면 즉시 판정됩니다. 정답은 통과 도장과 정답 해설로 표시되고, 오답은 다시 도장과 함께 내가 고른 답·정답·해설을 보여 줍니다. 오답 문항은 자동으로 오답 노트에 기록되며, 같은 문제를 다시 틀리면 오답 횟수가 누적됩니다.

시간은 관문 기록에 포함되지만, 빠르게 푸는 것만을 우선하지 않습니다. 정확도와 개념 이해를 중심으로 학습하고, 힌트 사용 여부와 재도전 기록은 개인 학습 기록으로 남습니다.

### 힌트와 기록

문제별 힌트는 정답을 바로 공개하지 않고, 판단 순서나 필요한 개념을 안내합니다. 관문은 시작 시각과 완료 시각을 기준으로 경과 시간을 기록하며, 정확도·힌트 사용·시도 횟수·최고 기록을 관문별로 보여 줍니다.

## 보스전과 특별 칭호

각 관문의 정규 문항을 통과하면 해당 차시의 핵심을 묻는 짧은 보스 문제가 열립니다. 보스 문제까지 해결해야 관문을 완전히 클리어한 것으로 처리되고 다음 길이 해금됩니다. 보스 클리어 시 차시별 특별 칭호가 부여되어 업적 보관소와 클리어 결과에 표시됩니다.

보스 화면은 일반 문제 화면과 구분되는 포스터형 레이아웃을 사용하며, 다음의 짧은 행동 순서를 안내합니다.

> **도전 → 판정 → 칭호**

## 오답 노트와 5문항 미니 복습전

오답 노트는 틀린 문제를 문제 ID와 관문별로 모아 보여 줍니다. 전체 보기와 관문별 필터를 사용할 수 있으며, 선택한 문제를 다시 풀거나 전체 오답을 순서대로 다시 도전할 수 있습니다. 재도전에서 정답을 맞히면 해당 문제는 목록에서 제거되고 화면에 **해결 완료** 도장이 표시됩니다.

오답 횟수는 개념별로 집계됩니다. 가장 많이 틀린 개념을 약점 개념으로 선정하고, 오답 노트의 **5문항 미니 복습전** 버튼으로 실제 문제은행에서 해당 개념에 맞는 문항을 구성합니다. 미니 복습전은 오답 기록을 삭제하지 않고 약한 규칙을 집중 연습하는 별도 회복 모드입니다.

> **오답 분석 → 5문항 → 규칙 회복**

## 수직선과 시각 학습 도구

범위 문제에서는 수직선이 단순한 장식이 아니라 정답을 판단하는 핵심 도구입니다. 수직선 문항은 눈금, 경계값, 채워진 점·빈 점, 화살표 방향을 구분하도록 구성되어 있습니다. 직접 조작형 문항에서는 눈금을 누르고 끝점 포함 여부와 방향을 선택해 자신의 범위를 표현합니다.

요금표 문항은 표의 조건을 읽어야 하며, 묶음 그림 문항은 상자나 스탬프의 묶음 수를 눈으로 확인한 뒤 올림·버림 결과를 고르게 합니다. 문항에 필요한 경우 차시별 상황 안내 카드가 함께 표시되어 **읽기 → 판단 → 제출**의 순서를 돕습니다.

## 진행 보상과 엔딩

완료한 관문은 지도에서 민트빛 경로로 영구 점등됩니다. 관문별 배지는 업적 보관소에 모이고, 최고 기록·정확도·시도 횟수·획득 칭호를 확인할 수 있습니다. 11개 관문과 최종 보스까지 모두 통과하면 성이 복구되고 폭죽과 최종 통과 도장이 나타나는 엔딩 화면으로 이동합니다.

## 저장 방식과 데이터 범위

현재 학습 데이터는 별도 계정 서버가 아니라 브라우저의 `localStorage`에 저장되는 클라이언트 중심 구조입니다. 따라서 같은 브라우저에서는 진행 기록이 유지되지만, 브라우저 저장소를 삭제하거나 다른 기기를 사용하면 기록이 이어지지 않을 수 있습니다.

주요 저장 대상은 다음과 같습니다.

| 저장 대상 | 용도 |
|---|---|
| `boundary-quest-records` | 관문 완료 여부, 시간, 정확도, 힌트, 시도와 최고 기록 |
| `boundary-wrong-notes` | 오답 문제, 내가 고른 답, 정답, 오답 횟수, 해설 |
| 업적·완료 상태 | 관문 배지, 칭호, 영구 점등 경로, 엔딩 진입 판단 |

## 로컬 실행

Node.js와 pnpm이 설치된 환경에서 다음 명령을 실행합니다.

```bash
pnpm install
pnpm dev
```

개발 서버는 Vite가 제공하며 기본 포트는 `3000`입니다. 프로덕션 빌드와 타입 검사는 다음과 같이 실행합니다.

```bash
pnpm check
pnpm build
```

코드 포맷을 확인하거나 적용하려면 다음 명령을 사용할 수 있습니다.

```bash
pnpm format
```

## 배포 메모

GitHub의 `main` 브랜치가 Vercel 프로젝트와 연결되어 있습니다. `main`에 push하면 Vercel이 자동으로 새 배포를 생성합니다. `vercel.json`은 Vite가 생성하는 `dist/public` 산출물을 사용하도록 설정되어 있으며, SPA의 루트 진입이 실제 앱 HTML을 제공하도록 구성되어 있습니다.

이미지는 저장소에 대용량 파일로 넣지 않고 `/manus-storage/` 경로의 프로젝트 관리 자산을 참조합니다. 배포 환경에서 해당 자산 URL이 유지되어야 하므로 이미지 경로를 임의로 로컬 파일 경로로 바꾸지 않습니다.

## 교육 콘텐츠 기준

문제는 초등학교 5학년 2학기 수학 1단원 「수의 범위와 어림하기」의 학습 요소를 중심으로 구성합니다. 특히 이상·이하·초과·미만의 경계값과 수직선 표현, 올림·버림·반올림의 기준, 실생활 단위와 조건 해석을 구분해 연습하도록 합니다. 현실성이 떨어지는 단위나 개인의 신체·성적을 판정하는 맥락은 사용하지 않고, 상자·스탬프·요금표·행사 안내와 같은 안전하고 관찰 가능한 상황으로 구성합니다.
