# [공유] 5학년 2학기 수학 1단원 「수의 범위와 어림하기」 퀘스트형 학습 앱

![경계선 퍼즐 — 수의 범위와 어림하기](https://rangepuzz-opw6l8em.manus.space/manus-storage/range-line-puzzle-indischool-thumbnail_264cf771.png)

5학년 2학기 수학 1단원 **「수의 범위와 어림하기」**를 복습하거나 개별 학습에 활용할 수 있도록, 한 차시씩 퀘스트를 통과하는 형태의 웹앱을 만들어 보았습니다.

학생이 문제를 푸는 동안에는 큰 제목이나 장식보다 **문제·선택지·제출 버튼이 먼저 보이도록** 화면을 정리했습니다. 반대로 관문 통과, 보스전, 업적 같은 보상 구간에서는 게임의 재미가 느껴지도록 구성했습니다.

> **앱 바로가기:** [경계선 퍼즐 — 수학 탐험대](https://rangepuzz-opw6l8em.manus.space)

| 구성 | 활용 포인트 |
|---|---|
| 11개 관문·210문항 | 차시별 핵심 개념을 기본·적용·오개념 교정 문제로 단계적으로 연습합니다. |
| 30초 진단 | 차시 시작 전, 한 문항으로 핵심 규칙을 빠르게 떠올립니다. 점수에는 반영되지 않습니다. |
| 수직선·요금표·묶음 그림 | 글만으로 이해하기 어려운 조건과 어림 상황을 시각 자료로 확인합니다. |
| 오답 노트·미니 복습전 | 틀린 문제를 다시 풀고, 많이 막힌 개념은 5문항 집중 복습으로 이어집니다. |
| 요점 노트 | 이상·이하·초과·미만, 올림·버림·반올림의 규칙과 예시를 학습지처럼 정리했습니다. |
| 보스전·업적 | 차시 마무리 문제와 칭호를 통해 학습 완료의 성취감을 줍니다. |

수업에서는 차시 도입 때 **30초 진단을 함께 확인**하고, 개인 활동 시간에는 각자 관문을 진행하게 한 뒤, 마무리 단계에서 오답 노트나 요점 노트로 돌아가게 하면 활용하기 좋았습니다. 특히 ‘이상·이하·초과·미만’의 기준값 포함 여부와 ‘올림·버림·반올림’의 상황 판단을 다시 확인할 때 사용할 수 있도록 구성했습니다.

학습 진행 기록과 오답 노트는 학생이 사용하는 **같은 브라우저에 저장**됩니다. 따라서 수업 중에는 가능하면 같은 기기와 같은 브라우저로 이어서 사용해 주세요.

아직 더 다듬을 부분이 있을 수 있습니다. 실제 수업에서 써 보시고 문항, 화면, 활동 흐름에서 개선하면 좋을 점이 있다면 편하게 의견 남겨 주세요. 감사합니다.
